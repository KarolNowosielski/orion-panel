# Instrukcje dla agentów

Kontynuuj w języku polskim. Ten projekt jest lokalną aplikacją bez backendu. Nie dodawaj kont, analityki, API ani usług przesyłających PDF. Użytkownik wybrał nazwę Orion Panel oraz upoważnił commity, tworzenie PR, przegląd i scalanie bez ponownego pytania.

Stosuj CONTRIBUTING.md. Przed zakończeniem uruchom `npm test`, sprawdź składnię i istotne zachowanie w przeglądarce. Każdą istotną decyzję zapisz jako nowy ADR z kontekstem, decyzją, alternatywami i skutkami. Nie zmieniaj istniejących zaakceptowanych ADR bez śladu; zastępuj nowym wpisem.

Nie twierdź, że plan koncepcyjny jest dokumentacją wykonawczą. Nie omijaj blokady GitHub dotyczącej zatwierdzania własnych PR. Pary napędów muszą być sąsiednie, nieparzysty/parzysty, w jednym module i systemie. Nie zmieniaj danych użytkownika na przykład bez potwierdzenia w interfejsie aplikacji.
